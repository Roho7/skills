# Engineering

Daily code work: checking UIs, recording demos, working through review.

- **[ask-my-opinion](./ask-my-opinion/SKILL.md)**: After agent work or a PR, interview you on every non-obvious autonomous decision until you agree on each one. User-invoked.
- **[record-demo](./record-demo/SKILL.md)**: Record a short screen-recording video of a feature you just implemented, by driving the running app in a real browser.
- **[review-comments](./review-comments/SKILL.md)**: Walk through a PR's unresolved review comments one at a time — brief, score, and fix each with the user's sign-off before moving on. User-invoked.
- **[visual-verification](./visual-verification/SKILL.md)**: Drive a real Chrome to check UI changes, with legible screenshots, accessibility snapshots, mocked API responses, request logs, GIF demos and PR image upload through the `shot` CLI, plus the iOS Simulator path for Safari bugs.
