# Productivity

How the agent talks and how you learn.

- **[chapterize](./chapterize/SKILL.md)**: Turn a concept you want to learn into a researched book chapter — theory, exercises, a builder's guide, and sources. User-invoked.
- **[rapid-fire](./rapid-fire/SKILL.md)**: Enter rapid-fire mode - answer every question in under 20 words until the user ends it. User-invoked.
- **[shh](./shh/SKILL.md)**: A super quiet way of speaking where one can only utter 3 short sentences. User-invoked.
